## Publish with GitHub Pages

For this static website, the simplest setup is to publish directly from the `main` branch.

1. Create a new GitHub repository, recommended name: `tam-tran-portfolio`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**.
6. Save.
7. GitHub Pages will provide the live URL.

Default project-site URL format:

```text
https://YOUR-GITHUB-USERNAME.github.io/tam-tran-portfolio/
```

If you later use a custom domain, follow `docs/CUSTOM_DOMAIN.md`.

## Updating the portfolio

Recommended workflow:

1. Edit the relevant file.
2. Preview locally in a browser.
3. Commit the change with a clear message.
4. Push to `main`.
5. GitHub Pages republishes the site automatically.

Example commit messages:

```text
Update project case study copy
Add new strategic partnership project
Refine Vietnamese translation
Update career metrics
Refresh portfolio colors
```
